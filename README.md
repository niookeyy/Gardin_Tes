# HydroWave — Landing Page

Selamat bagi anda yang sudah menemukan halaman ini, saya membuat halaman ini untuk tes dari perusahaan Gardin.

## Tentang Project

HydroWave adalah landing page produk botol minum yang saya buat menggunakan **HTML** dan **Tailwind CSS**. Project ini mencakup beberapa section utama:

- **Navbar** — navigasi responsif dengan menu hamburger di tampilan mobile (mengikuti pola dropdown ala Flowbite)
- **Hero** — section pembuka dengan background image
- **Produk** — menampilkan varian produk
- **Galeri** — kumpulan gambar produk
- **Blog** — bagian artikel/konten
- **Tentang Kami** — informasi seputar brand
- **Hubungi Kami** — bagian kontak

## Proses Pengerjaan

Dalam mengerjakan project ini, saya membangun struktur dan konten halaman sendiri, dan menggunakan bantuan AI (Claude) untuk sebagian proses debugging dan penyesuaian styling — misalnya memperbaiki bug pada logika toggle menu navbar (ada ID duplikat yang menyebabkan menu tidak berfungsi dengan benar) dan menerapkan efek background image pada section hero. Saya memahami dan bisa menjelaskan setiap bagian dari kode yang digunakan di project ini.
